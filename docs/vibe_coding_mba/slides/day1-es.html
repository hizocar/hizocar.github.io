Publicar son cuatro pasos, de tu escritorio a la calle

Commitguarda una versión con nombre
Pusha un repositorio privado de GitHub
Importen vercel.com/new, una vez
Abrirtu URL, en tu celular

Lo que está publicado está en GitHub. Cada push a main vuelve a publicar.

Publicar, clic a clic

1
Pídele a Claude que revise“Sin llaves, sin archivos .env, todo con commit. No hagas push.”
2
Source Control → Publish BranchElige “Publish to GitHub private repository”.
3
vercel.com/new → Import → DeployNo cambies nada. ¿No aparece el repositorio? Adjust GitHub App Permissions.
4
Ábrela en tu celularLuego un cambio, commit y Sync Changes: se publica sola.

Tu presentación en cinco minutos

Pégalo en Claude Code, dentro de tu proyectoCrea una presentación HTML de 6 diapositivas sobre mi proyecto en un solo archivo, public/slides.html. Diapositivas: el problema, para quién es, qué hace mi web, cómo funciona, por qué ahora, qué necesito. Una idea por diapositiva, letra grande, los colores de mi sitio, flechas del teclado para avanzar, que funcione en el celular. Sin librerías externas.

Después abre localhost:3000/slides.html. Commit y push: también queda publicada en tu URL.
