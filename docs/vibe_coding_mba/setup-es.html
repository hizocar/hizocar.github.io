Guía de instalación

Tres cuentas, cuatro programas, cinco pruebas. Unos 45 minutos, antes del domingo 29 de noviembre. No necesitas saber programar.

Hazlo en tu casa, antes del día 1. Si llegas con las cuentas creadas y los programas instalados, el día 1 se va en construir y no en esperar correos de confirmación. Si algo falla, ven igual: el día 1, de 08:20 a 09:00, revisamos la instalación de todos y los compañeros se ayudan entre sí.

Regla de oro. Si un comando responde con un error en rojo, no sigas al paso siguiente. Copia el error completo y tráelo a clases, o pégalo en claude.ai con: “¿Qué significa esto y cómo lo arreglo en Mac / Windows?”

Parte 2 · Programas (30 minutos)

Todo pasa en una terminal, una ventana donde le escribes instrucciones al computador. En Mac: ⌘ + Espacio, escribe Terminal, Enter. En Windows: menú Inicio, escribe PowerShell y ábrelo. Para ejecutar un comando, cópialo, pégalo en la terminal y presiona Enter. Después de cada programa hay una prueba: no avances si falla.

1. VS Code

Descárgalo desde code.visualstudio.com e instálalo como cualquier programa. En Mac, arrástralo a Aplicaciones; no lo abras desde Descargas. Ábrelo y, en el menú de arriba, elige Terminal → New Terminal. De aquí en adelante, usa esa terminal.

Prueba: code --version muestra un número. En Mac, si dice command not found: code: presiona ⌘ + Shift + P, escribe Shell Command: Install ‘code’ command in PATH y presiona Enter.

2. Git

En la terminal · Mac
xcode-select --install

Se abre una ventana: acepta e instala, demora unos minutos. Windows: descárgalo desde git-scm.com y deja todas las opciones por defecto. Después dile a Git quién eres, con el mismo correo de GitHub:

En la terminal · Mac y Windows
git config --global user.name "Tu Nombre" git config --global user.email "tu-correo@ejemplo.com"

Prueba: git --version muestra algo como git version 2.4x.

3. Node.js

Entra a nodejs.org, descarga la versión LTS (la recomendada, no “Current”) e instálala con las opciones por defecto. Después cierra y vuelve a abrir VS Code; si no, su terminal no verá el programa nuevo.

Prueba: node -v y npm -v muestran números; Node debe ser 22 o superior.

Solo en Windows: si npm -v responde running scripts is disabled on this system, ejecuta Set-ExecutionPolicy -Scope CurrentUser RemoteSigned, responde Y y vuelve a abrir la terminal.

4. Claude Code

En la terminal · Mac
curl -fsSL https://claude.ai/install.sh | bash
En PowerShell · Windows
irm https://claude.ai/install.ps1 | iex

Cierra y vuelve a abrir la terminal, y escribe claude. La primera vez te pide iniciar sesión: elige tu cuenta de Claude (Pro o superior), acepta en el navegador y vuelve a la terminal.

Prueba: dentro de Claude Code, escribe /status. Aparece tu cuenta. Escribe /exit para salir. Ejecutar claude una vez en la terminal también deja configurado el catálogo oficial de plugins de Anthropic, que usarás el domingo.

La extensión de VS Code. En VS Code, abre Extensions (el ícono de cuadritos a la izquierda, o ⌘/Ctrl + Shift + X), busca Claude Code, publicada por Anthropic, e instálala. Abre cualquier archivo: aparece un ícono Spark (✻) arriba a la derecha del editor, y al hacer clic se abre Claude en un panel junto a tus archivos. El panel y la terminal son el mismo Claude. En clases usamos el panel, y la terminal cuando haga falta.

Dónde viven tus proyectos

Crea una carpeta llamada Proyectos en tu carpeta de usuario: /Users/tu-nombre/Proyectos en Mac, C:\Users\tu-nombre\Proyectos en Windows.

No en el Escritorio, en Documentos, iCloud, OneDrive ni Google Drive. Esas carpetas sincronizan y “optimizan” archivos mientras Claude los escribe, y han llegado a borrar proyectos completos. Tu respaldo es GitHub, no la carpeta sincronizada.

Un calentamiento que ahorra tiempo el domingo (5 a 10 minutos)

Treinta notebooks descargando el mismo proyecto web por el wifi de la sala es lento. Descárgalo una vez en tu casa, así el domingo casi todo sale de tu propio notebook. En la terminal, una línea a la vez:

En la terminal · Mac
mkdir -p ~/Proyectos && cd ~/Proyectos npx --yes create-next-app@latest calentamiento --yes
En la terminal · Windows
mkdir $HOME\Proyectos -Force; cd $HOME\Proyectos npx --yes create-next-app@latest calentamiento --yes

Termina con Success! Created calentamiento. Después puedes borrar esa carpeta; era solo un ensayo.

Las cinco pruebas

  • code --version muestra un número.
  • git config --global user.email muestra el correo de tu cuenta de GitHub.
  • node -v muestra 22 o superior.
  • claude abre y, dentro, /status muestra tu cuenta (después /exit).
  • En VS Code, el ícono Spark (✻), o ✻ Claude Code en la barra de estado de abajo, abre el panel de Claude Code.

En un notebook del trabajo

Un notebook administrado por tu empleador puede bloquear la instalación de programas, o el instalador de Claude Code. Prueba primero en tu casa. Si está bloqueado, trae un notebook personal o pide permiso a tu equipo de TI antes del domingo. No te saltes los controles de seguridad de tu empleador.

Antes del día 2

A más tardar el domingo 10 de enero de 2027, crea una cuenta gratis en Supabase con Continue with GitHub. El día 2 la conectamos a Claude para darle a tu web una base de datos y un inicio de sesión. El plan gratis pausa un proyecto después de una semana sin uso; un clic en Restore en su panel lo reactiva. Todo lo demás que necesite el día 2 aparecerá en la página de su clase.
