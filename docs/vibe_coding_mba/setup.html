Setup guide

Three accounts, four programs, five tests. About 45 minutes, before Sunday 29 November. No programming required.

Do this at home, before Day 1. If you arrive with the accounts created and the programs installed, Day 1 goes to building instead of waiting for confirmation emails. If something fails, come anyway: from 08:20 to 09:00 on Day 1 there is a setup check, and neighbors help neighbors.

Golden rule. If a command answers with an error in red, do not continue to the next step. Copy the whole error and bring it to class, or paste it into claude.ai with: “What does this mean and how do I fix it on Mac / Windows?”

Part 2 · Programs (30 minutes)

Everything happens in a terminal, a window where you type instructions to your computer. On a Mac: ⌘ + Space, type Terminal, Enter. On Windows: Start menu, type PowerShell, open it. To run a command, copy it, paste it into the terminal and press Enter. After each program there is a test: do not move on if it fails.

1. VS Code

Download it from code.visualstudio.com and install it like any program. On a Mac, drag it into Applications; do not open it from Downloads. Open it, and in the top menu choose Terminal → New Terminal. From here on, use that terminal.

Test: code --version shows a number. On a Mac, if it says command not found: code: press ⌘ + Shift + P, type Shell Command: Install ‘code’ command in PATH, and press Enter.

2. Git

In the terminal · Mac
xcode-select --install

A window opens: accept and install, which takes a few minutes. Windows: download it from git-scm.com and keep every default option. Then tell Git who you are, with the same email as GitHub:

In the terminal · Mac and Windows
git config --global user.name "Your Name" git config --global user.email "your-email@example.com"

Test: git --version shows something like git version 2.4x.

3. Node.js

Go to nodejs.org, download the LTS version (the recommended one, not “Current”) and install it with the default options. Then close and reopen VS Code, or its terminal will not see the new program.

Test: node -v and npm -v both show numbers; Node must be 22 or higher.

Windows only: if npm -v answers running scripts is disabled on this system, run Set-ExecutionPolicy -Scope CurrentUser RemoteSigned, answer Y, and reopen the terminal.

4. Claude Code

In the terminal · Mac
curl -fsSL https://claude.ai/install.sh | bash
In PowerShell · Windows
irm https://claude.ai/install.ps1 | iex

Close and reopen the terminal, then type claude. The first time, it asks you to sign in: choose your Claude account (Pro or higher), accept in the browser, and come back to the terminal.

Test: inside Claude Code, type /status. Your account appears. Type /exit to leave. Running claude once in the terminal also sets up Anthropic’s official plugin catalog, which you use on Sunday.

The VS Code extension. In VS Code, open Extensions (the squares icon on the left, or ⌘/Ctrl + Shift + X), search for Claude Code published by Anthropic, and install it. Open any file: a Spark icon (✻) appears at the top right of the editor, and clicking it opens Claude in a panel next to your files. The panel and the terminal are the same Claude. In class we use the panel, and the terminal when we need it.

Where your projects live

Create a folder called Proyectos in your user folder: /Users/your-name/Proyectos on a Mac, C:\Users\your-name\Proyectos on Windows.

Not on the Desktop, in Documents, iCloud, OneDrive or Google Drive. Those folders sync and “optimize” files while Claude is writing them, and they have deleted whole projects. Your backup is GitHub, not the sync folder.

A warm-up that saves time on Sunday (5 to 10 minutes)

Thirty laptops downloading the same web project on the room’s wifi is slow. Download it once at home, so that on Sunday most of it comes from your laptop. In the terminal, one line at a time:

In the terminal · Mac
mkdir -p ~/Proyectos && cd ~/Proyectos npx --yes create-next-app@latest calentamiento --yes
In the terminal · Windows
mkdir $HOME\Proyectos -Force; cd $HOME\Proyectos npx --yes create-next-app@latest calentamiento --yes

It ends with Success! Created calentamiento. You can delete that folder afterwards; it was only a rehearsal.

The five tests

  • code --version shows a number.
  • git config --global user.email shows the email of your GitHub account.
  • node -v shows 22 or higher.
  • claude opens, and inside it /status shows your account (then /exit).
  • In VS Code, the Spark icon (✻), or ✻ Claude Code in the status bar at the bottom, opens the Claude Code panel.

On a work laptop

A laptop managed by your employer may block installing programs, or block the Claude Code installer. Try at home first. If it is blocked, bring a personal laptop, or ask your IT team for permission before Sunday. Do not work around your employer’s security controls.
