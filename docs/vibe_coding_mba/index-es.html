Entre el primer y el segundo día hay siete semanas: tiempo para entregar el brief, seguir mejorando tu web y prepararte para el día 2. El calendario tiene cada bloque, pausa y fecha de entrega.

Antes del domingo 29 de noviembre

  • Contrata el plan Claude Pro en claude.ai, unos USD 20 al mes, pagado por cada estudiante. Claude Code no funciona con el plan gratis.
  • Crea tus cuentas de GitHub y Vercel, e instala VS Code, Git, Node.js y Claude Code: la guía de instalación, unos 45 minutos.
  • Escribe cinco líneas sobre tu propia idea: un negocio, un proyecto, un servicio o un portafolio. El domingo construyes su web.
  • Trae un notebook en el que puedas instalar programas, y su cargador.

Qué construyes y con qué te vas

Cada equipo lleva un problema real de la organización de uno de sus integrantes hasta una aplicación web publicada con una capacidad de IA, luego la gobierna y la presenta ante un panel. En el camino usas los componentes del trabajo actual con IA.

Páginas web y aplicaciones
Una aplicación publicada con inicio de sesión y datos guardados, y una página pública que la explica.
Skills
"Cómo lo hacemos aquí", empaquetado para que el asistente lo repita.
Conectores y MCP
Acceso acotado a los sistemas de la empresa: primero leer, después escribir.
Agentes
Un modelo que da pasos con herramientas y espera tu aprobación.
Automatizaciones
Trabajo que parte con un horario, con un responsable y un registro.
Presentaciones
Una presentación para el Demo Day generada a partir de tu evidencia y revisada por ti.

No se requiere ni se supone experiencia en programación. Te vas con un producto que funciona, un set de pruebas y un memo de riesgos, un pequeño sistema personal para trabajar con IA y una forma probada de decidir entre mantener un prototipo, pasárselo a ingeniería, comprar un producto o parar.

Los trabajos escritos se entregan a las 23:59 del día indicado; el Demo Day es en la sala. Todo se evalúa con una sola rúbrica (en inglés). El curso se aprueba con 55 de 100. Usar IA es obligatorio y debe declararse.

Una regla desde el primer minuto

Hasta que tu equipo haya completado el laboratorio de la clase 4, cerrado todos los hallazgos críticos y tenga el acuerdo escrito de la organización dueña de los datos, usa solo información inventada o anonimizada: nada de nombres, teléfonos, direcciones ni RUT reales. La mayoría de los equipos se quedará con datos anonimizados hasta el Demo Day, y eso no le cuesta nada en la nota.
