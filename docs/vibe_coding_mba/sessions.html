Schedule

Three days, 20 contact hours in two-hour blocks. Breaks and lunch are not counted as contact time.

The course runs on one Sunday in November and one weekend in January, with seven weeks in between. Day 1 is a hands-on workshop: every student builds their own web, for their own idea, with Claude Code. The programme of Days 2 and 3 is published before Day 2.

Day 1, Sunday 29 November 2026

Class 1. Your first web with Claude Code

Class page: Class 1 · Your first web with Claude Code · Slides: Day 1

Build goal. Every student, on their own idea: a web live at a public address, a six-slide HTML deck published with it, and a personal skill that keeps their brand.

Before Day 1. The setup guide, about 45 minutes: a Claude Pro plan (paid by each student), GitHub and Vercel accounts, VS Code, Git, Node.js and Claude Code installed, and five lines about your idea. Bring the laptop and its charger.

08:00 to 10:00. Live demo: a page from an empty folder to a phone in about ten minutes (20). Setup check: the five tests pass on every laptop (40). How it works, with three short tries in Claude Code: what a model does, tokens and the usage limit, the context window, chat versus agent, a good request, plan mode and permissions (60).

10:15 to 12:15. Lab 1, your web: brief, plan mode, build, localhost, one change at a time, going back with rewind, a first commit (75). Skills and memory: the frontend-design plugin from the official catalog, a redesign with it, CLAUDE.md with /init (45).

12:30 to 14:30. Publish: a private GitHub repository, an import in Vercel, the address open on a phone, a change that publishes itself (45). An HTML deck in five minutes, saved in the project and published with it (15). Your own skill, my-brand, created with skill-creator and tested in a clean conversation (35). Sixty-second pitches with the deck, what comes on Days 2 and 3, and M1 explained (25).
