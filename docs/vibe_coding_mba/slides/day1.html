# Dulce Norte web
## What it is
Catalog and a waitlist for the weekly menu.
## Rules
- Next.js and Tailwind, deployed on Vercel.
- Never put secret keys in the code.
## Rules from real bugs
- Show a clear message when saving fails.

Your deck in five minutes

Paste in Claude Code, inside your projectCreate a 6-slide HTML presentation about my project in a single file, public/slides.html. Slides: the problem, who it is for, what my web does, how it works, why now, what I need. One idea per slide, large type, my site's colors, arrow keys to move, works on a phone. No external libraries.

Then open localhost:3000/slides.html. Commit and push: it is live at your URL too.

Your own skill: my-brand

Paste in Claude Code, with your own colorsUse skill-creator to create a personal skill called my-brand with my colors (#XXXXXX, #XXXXXX), my fonts, and the tone of my texts: close, no jargon. Its description must say to use it whenever I ask for a page, a slide or a text for my project. Save it in ~/.claude/skills/my-brand, not inside this project. No test cases or evals: just write the SKILL.md.

Test it in a new conversation: “Make me a one-page price list for my project.” No colors, no tone. Does it come out in your brand?
